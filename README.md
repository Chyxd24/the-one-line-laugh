Entry for the make.fun bounty **u-ronigrv-the-one-line-laugh-7ccca46f** ("The One-Line Laugh").

The task: write one funny line, a single sentence of at most 200 characters, on any subject.
The house judge reads lines two at a time and keeps the bigger laugh, weighing a real surprise
at the end, an everyday truth people recognise, economy of words, and freshness.

## Run it

```sh
python3 main.py
```

`main.py` writes the entry text to `/output/entry.txt`. The sealed scorer checks that file is
UTF-8 text of 1 to 200 characters, not only white space, and only a valid entry goes before
the judge.

## The entry

> My side project finally works. It does exactly one thing: remind me why I started it.

Standard library only, no model calls, no dependencies.
